# gangneung-my-ai-lab
강릉 주민 맞춤형 AI 교육·실습 플랫폼 — 전자책형 수업 안내와 AI 실습 웹앱

## 공개 시안
https://gangneung-my-ai-lab.yoon2566.workers.dev

기초 7개·중급 7개·고급 8개, 총 22개 주제의 단일 HTML 실습 시안입니다.
목차 검색, 수업 이동, 예시 질문 적용, 체크리스트 저장을 제공합니다.
현재 AI API는 연결되지 않았으며 수업별 준비된 예시 응답을 표시합니다.

## 파일
- index.html: 외부 의존성 없는 화면 원본
- worker.js: Cloudflare Workers 응답 모듈
- 시안_설계메모.md: 참고 분석과 구현 범위
- 시안_PC.png / 시안_모바일.png: 화면 캡처

2026-11-08 Cloudflare 배포 후 HTTP 200 및 로컬 HTML과 응답 본문 일치를 확인했습니다.

## 모바일 디자인 개정
Craft Anything으로 공식 실습 화면을 분석하고 디자인을 재구현했습니다.
모바일은 수업/실습 탭으로 분리했으며 키보드로 화면 높이가 줄어드는 상황을 고려했습니다.
360·390px, 글자 125% 확대, 390×400px 화면과 태블릿·PC에서 검증했습니다.
자세한 변경과 검증 한계는 모바일_디자인_개선.md에 기록했습니다.
